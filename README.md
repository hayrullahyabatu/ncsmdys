# Müzik Dersi Öğrenci Takip Platformu

Bu depo, Node.js/Express ve React.js kullanılarak hazırlanan basit bir öğrenci takip sistemi taslağı içerir.

## Klasörler

- `backend/` - API ve veritabanı işlemleri
- `frontend/` - Kullanıcı arayüzü

## Başlatma

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npm run tailwind &
npm start
```

Gerekli MongoDB servisi `mongodb://localhost:27017/music-school` adresinde çalışıyor olmalıdır.
